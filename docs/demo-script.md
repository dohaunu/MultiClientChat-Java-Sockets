# Three-minute demonstration script

**0:00–0:30** Introduce the two Maven projects, point out `ServerCore` and `ClientConnection` as independent networking/model code, and `ServerApp`/`ClientApp` as the JavaFX UI.

**0:30–1:00** Start server; show status, logs, empty users list, and external `server.properties`.

**1:00–1:45** Launch Alice and Bob; show usernames and server's randomly colored user entries. Send messages in both directions; point out the time.

**1:45–2:15** Type `allUsers` for Alice and explain that the response is private. Launch unnamed Guest; show that message input is disabled while incoming messages remain visible.

**2:15–2:40** Use LEAVE on Bob and type `bye` on Alice; show list and system log changes.

**2:40–3:00** Show UML files, JAR artifacts in target folders, and README / GitHub repository.
